Surrogate Models for Multi-Sector ESOMs

Data, code and results for regression, classifier-regressor, and informed joint-learning models.

Introduction

This dashboard contains the data, code, results and analysis of the study 'Design and evaluation of surrogate models for multi-sector energy system optimisation models'.

How To Navigate

Results Dashboard

Results Dashboard shows the analysis of the study. The first tab contains results of comparing conventional regression methods GP, MLP and XGB for the performance metrics. The second tab contains results of the comparison between conventional XGB and a classifier-regressor XGB method. The third tab shows the performance of surrogate methods for varying ESOM outputs. The fourth tab shows how the constraint-aware method performs compared to the classifier-regressor method.

Subchapter 1: Regression Methods (GP, MLP, XGB)

Comparison of conventional regression approaches across shared targets.

Three conventional regression methods (GP, MLP, and XGB) are compared across 463 shared target variables.

The results indicate similar predictive accuracy across methods, while XGB is consistently more computationally efficient.

Comparison of conventional regression methods (mean)

Conventional Regression: GP vs MLP vs XGB (distribution)

Data source: test regression methods/surrogate_run_log.csv

Boxplots summarize NRMSE, NMAE, RTA1%, RTA5%, RTA10%, training time, and prediction time across shared targets for GP, MLP, and XGB.

Lower is better for NRMSE, NMAE, training time, and prediction time, while higher is better for RTA metrics. Outliers are removed using Tukey's rule (values beyond 1.5 x IQR).

Correlation Between Accuracy Metrics: XGB vs MLP vs GP

Pairwise method correlations across NRMSE, NMAE, RTA1%, RTA5%, and RTA10%.

Similar predictive behavior is reflected by strong correlations, with XGB vs GP around 0.98 and correlations involving MLP around 0.87.

Cross-Validation Fold Sensitivity (XGB)

Comparison of 5-fold and 7-fold results against the 6-fold XGB baseline.

Subchapter 2: XGB+classifier

Pairwise comparison and distribution analysis.

For targets with recurring values, the classifier-regressor improves RTA and NMAE relative to conventional XGB, with the largest gains in RTA1/5/10.

The improvement comes with higher computational cost: training and prediction time increase compared with baseline XGB.

The classifier-regressor is trained on shared targets, while performance discussion focuses on recurring-value targets where classification is relevant.

XGB vs XGB+classifier

Direct comparison table across aligned targets.

The table summarizes how adding the classifier changes both accuracy and computational cost for the same target set.

XGB vs XGB+classifier Metric Distributions

Recreated distribution figure for regressor versus classifier-regressor across seven metrics.

Distribution plots compare conventional XGB and the classifier-regressor across recurring-value targets.

Boundary Sensitivity (XGB+classifier)

Average metric values for classifier-regressor boundaries X=10, 20, 30, and 40.

Sensitivity analyses indicate that varying the recurrence threshold between 10 and 40 has a negligible effect on classifier-regressor performance.

Subchapter 3: Performance vs characteristics

Classifier performance figures by variable and data characteristics.

This chapter examines how data type, variable type, and recurring-value structure relate to predictive accuracy and efficiency.

Effect of Adding Classifier

Data source: effect adding classifier/2fold_performance.csv

Training and prediction times increase with the number of recurring-value categories, while predictive performance varies by target data type.

NRMSE tends to be highest for discrete outputs and lower for semi-continuous/continuous outputs, whereas NMAE differences are generally smaller.

Additional diagnostics for the selected classifier method.

Pearson Correlation Matrix (Classifier-Regressor)

Average Accuracy by Value Distribution Type

Subchapter 4: Informed classifier-regressor

Table-only pairwise comparison plus informed-hybrid distribution analysis.

The informed classifier-regressor eliminates capacity-to-activity constraint violations while preserving similar predictive performance.

Compared with the classifier-regressor baseline, changes in NMAE and RTA metrics are small.
